## 2024-05-18 - Transaction Details Modal Close Button\n**Learning:** Modals can sometimes be missing explicit close buttons or lack ARIA attributes linking the title to the dialog role.\n**Action:** Update modals to include a standard `modal-header` with an `h2` and an explicitly labeled close button using `XMarkIcon`.
## 2026-10-19 - Focus Management in Modals\n**Learning:** When users open creation or search modals, forcing them to manually click the first input field adds unnecessary friction and violates WAI-ARIA best practices for dialog focus management.\n**Action:** Use the `autoFocus` attribute on the primary `<input>` element within React modal components (e.g., `CreatePortfolioModal`, `GoalFormModal`, `AddAssetToWatchlistModal`, `AssetLinkModal`) to immediately capture keyboard focus upon opening.

# Feature Specification: Income Source & Entry Data Management (FR16.1 & FR16.2)

**Feature ID:** FR16.1 & FR16.2  
**Status:** 📝 Planned  
**Title:** Income Source & Entry Data Management with TDS Tracking  
**GitHub Issue:** [#517](https://github.com/aashishbhanawat/ArthSaarthi/issues/517)  
**User Story:** As a user tracking my financial picture, I want to log income sources, individual income entries, and Tax Deducted at Source (TDS), so that I can maintain a clean ledger of my gross income and tax credits for annual tax filing.

---

## 1. Sub-Task Breakdown & Implementation Modules

1. **Module 1.1 (Database & Models):** Create `IncomeSource` and `IncomeEntry` SQLAlchemy models with `EncryptedString` columns for sensitive fields, plus Alembic migration.
2. **Module 1.2 (CRUD & Services):** Implement `crud_income_source` and `crud_income_entry` with strict tenant isolation (`user_id` verification).
3. **Module 1.3 (Backend APIs):** Expose `/api/v1/income/sources` and `/api/v1/income/entries` CRUD REST endpoints.
4. **Module 1.4 (Frontend UI):** Build `IncomePage.tsx`, source modal, entry logger modal, and responsive income cards/tables.

## 3. Test Plan & Corner Cases

### 3.1. Corner Cases
* **TDS Exceeding Gross Income:** Form validation preventing `tds_amount > gross_amount`.
* **Zero TDS Entries:** Logged freelance or rental income with ₹0 TDS processed cleanly.
* **Foreign Currency Income:** Foreign currency earnings converted to INR using transaction date FX rate.
* **IDOR Protection:** Attempting to edit or delete income entries belonging to another user returns HTTP 403 Forbidden.

## 6. Database Schema & Security Encryption (`EncryptedString`)

To protect user financial privacy on local desktop (PyInstaller) and mobile (Android SQLite) databases, sensitive text and monetary fields use `EncryptedString` (AES-256-GCM encryption key managed by `KeyManager`):

```sql
CREATE TABLE income_sources (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    name VARCHAR NOT NULL,       -- EncryptedString in desktop/mobile
    category VARCHAR NOT NULL,   -- SALARY, FREELANCE, RENTAL, etc.
    payer_name VARCHAR           -- EncryptedString in desktop/mobile
);

CREATE TABLE income_entries (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    source_id INTEGER NOT NULL REFERENCES income_sources(id),
    financial_year VARCHAR NOT NULL,
    entry_date DATE NOT NULL,
    gross_amount VARCHAR NOT NULL,  -- EncryptedString in desktop/mobile
    tds_amount VARCHAR NOT NULL,    -- EncryptedString in desktop/mobile
    net_amount VARCHAR NOT NULL,    -- EncryptedString in desktop/mobile
    notes TEXT                      -- EncryptedString in desktop/mobile
);
```

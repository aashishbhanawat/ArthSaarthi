# Feature Specification: Income Entry & TDS Logging (FR16.2)

**Feature ID:** FR16.2  
**Status:** 📝 Planned  
**Title:** Income Entry Logging with Tax Deducted at Source (TDS)  
**GitHub Issue:** [#517](https://github.com/aashishbhanawat/ArthSaarthi/issues/517)  
**User Story:** As a user tracking my financial health, I want to log individual income entries against defined income sources along with Tax Deducted at Source (TDS), so that I can maintain a clean ledger of my gross income and tax credits for annual tax filing.

---

## 1. Sub-Task Breakdown & Implementation Modules

1. **Module 2.1 (Database Model):** `IncomeEntry` SQLAlchemy model linked to `IncomeSource` via `source_id` foreign key, incorporating `EncryptedString` for sensitive financial amounts.
2. **Module 2.2 (CRUD & Services):** Implement `crud_income_entry` with validation enforcing `tds_amount <= gross_amount` and strict tenant authorization (`user_id`).
3. **Module 2.3 (Backend APIs):** Expose `/api/v1/income/entries` REST endpoints (`GET`, `POST`, `PUT`, `DELETE`).
4. **Module 2.4 (Frontend UI):** Build `IncomeEntryModal.tsx` form modal and entry ledger table under `IncomePage.tsx`.

---

## 2. Backend & Frontend Responsibilities

* **Backend (`backend/app/models/income.py` & `backend/app/api/v1/endpoints/income.py`):**
  - Database schema definition for `IncomeEntry`.
  - Pydantic schema validation (`app/schemas/income.py`).
  - Compute net amount (`gross_amount - tds_amount`).
  - Calculate cumulative Financial Year gross income and TDS totals.
* **Frontend (`frontend/src/pages/IncomePage.tsx` & `IncomeEntryModal.tsx`):**
  - Interactive Income Entry logger modal with Gross Amount, Date, TDS Amount, Net Amount (auto-calculated), and Notes.
  - Table displaying logged income transactions with filtering by Financial Year and Source.
  - Privacy Mode currency masking (`usePrivacySensitiveCurrency`).

## 3. Test Plan & Corner Cases

### 3.1. Corner Cases
* **TDS Exceeding Gross Amount:** Form validation preventing `tds_amount > gross_amount`.
* **Zero TDS Entries:** Logged freelance, interest, or rental income with ₹0 TDS processed cleanly.
* **Foreign Currency Income:** Foreign currency entries converted to INR using transaction date FX rates.
* **IDOR Protection:** Attempting to edit or delete income entries belonging to another user returns HTTP 403 Forbidden.

## 6. Database Schema & Security Encryption (`EncryptedString`)

To protect user financial privacy on local desktop (PyInstaller) and mobile (Android SQLite) databases, all monetary fields and notes use `EncryptedString` (AES-256-GCM encryption key managed by `KeyManager`):

```sql
CREATE TABLE income_entries (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    source_id INTEGER NOT NULL REFERENCES income_sources(id),
    financial_year VARCHAR NOT NULL,
    entry_date DATE NOT NULL,
    gross_amount VARCHAR NOT NULL,  -- EncryptedString in desktop/mobile
    tds_amount VARCHAR NOT NULL,    -- EncryptedString in desktop/mobile
    net_amount VARCHAR NOT NULL,    -- EncryptedString in desktop/mobile
    notes TEXT                      -- EncryptedString in desktop/mobile
);
```

# Feature Specification: Tax-Deductible Expense & Investment Logging (FR16.3)

**Feature ID:** FR16.3  
**Status:** ✅ Completed  
**Title:** Tax-Deductible Expense & Investment Logging under Chapter VI-A  
**GitHub Issue:** [#518](https://github.com/aashishbhanawat/ArthSaarthi/issues/518)  
**User Story:** As a taxpayer, I want to log tax-deductible expenses and eligible investments under Chapter VI-A (such as Section 80C, 80D, 80CCD), so that I can track section limits and optimize annual tax savings.

---

## 1. Sub-Task Breakdown & Implementation Modules

1. **Module 1.1 (Database & Models):** Create `TaxDeduction` SQLAlchemy model with `EncryptedString` columns for sensitive fields, plus Alembic migration.
2. **Module 1.2 (Backend Logic & Statutory Capping):** Implement statutory ceiling cap logic (80C: ₹1.5L, 80D: ₹25k/50k, 80CCD: ₹50k, 80TTA/TTB).
3. **Module 1.3 (Backend APIs):** Expose `/api/v1/tax/deductions` and `/api/v1/tax/deductions/summary` endpoints.
4. **Module 1.4 (Frontend UI):** Build `DeductionsPage.tsx`, interactive statutory limit progress meters, and deduction entry modal.

## 3. Test Plan & Corner Cases

### 3.1. Corner Cases
* **Deductions Exceeding Statutory Cap:** Logging ₹2,50,000 under Section 80C displays ₹2.5L invested, but caps eligible tax deduction calculation at statutory limit ₹1,50,000.
* **Senior Citizen Health Insurance (Section 80D):** Higher limit ₹50,000 applied for senior citizens / parents.
* **Auto-linking PPF & ELSS:** Cross-referencing existing PPF investments without double counting.

## 6. Database Schema & Security Encryption (`EncryptedString`)

To protect user financial privacy on local desktop (PyInstaller) and mobile (Android SQLite) databases, sensitive text and monetary fields use `EncryptedString` (AES-256-GCM encryption key managed by `KeyManager`):

```sql
CREATE TABLE tax_deductions (
    id SERIAL PRIMARY KEY,
    user_id INTEGER NOT NULL REFERENCES users(id),
    financial_year VARCHAR NOT NULL,
    section VARCHAR NOT NULL,      -- SEC_80C, SEC_80D, SEC_80CCD_1B, etc.
    title VARCHAR NOT NULL,        -- EncryptedString in desktop/mobile
    amount VARCHAR NOT NULL,       -- EncryptedString in desktop/mobile
    deduction_date DATE NOT NULL,
    proof_notes TEXT               -- EncryptedString in desktop/mobile
);
```

# Feature Specification: Structured Tax Summary Report & Tax Profile Dashboard (FR16.4 & FR16.4.1)

**Feature ID:** FR16.4 & FR16.4.1  
**Status:** 📝 Planned  
**Title:** Structured Tax Summary Report, Old vs New Regime Engine & Mandatory Legal Disclaimer  
**GitHub Issue:** [#519](https://github.com/aashishbhanawat/ArthSaarthi/issues/519)  
**Historical Benchmarks:** Excel Salary Tax Calculators (`local/TaxCalc_2022.xlsx` through `local/TaxCalc_2027.xlsx`)  
**User Story:** As a user planning my annual taxes, I want a consolidated Financial Year Tax Readiness summary report with clear legal disclaimers, so that I can view my overall tax profile, gross income, TDS credits, eligible deductions, capital gains, and estimated net tax liability for planning purposes while knowing that official filing requires a CA.

---

## 1. Sub-Task Breakdown & Implementation Modules

1. **Module 1.1 (Versioned Tax Rules Registry):** Configurable, versioned statutory tax rule engine (`backend/app/core/tax_rules_registry.py`) pre-seeded with historical tax rules for FY 2021-22 through FY 2026-27 derived directly from `local/TaxCalc_2022.xlsx` to `local/TaxCalc_2027.xlsx`.
2. **Module 1.2 (Salary & Allowances Exemptions Engine):** Calculates HRA exemption (Sec 10(13A)), Standard Deduction (Sec 16(ia)), Professional Tax (Sec 16(iii)), LTA (Sec 10(5)), Children Education Allowance (Sec 10(14)), and Employer NPS (Sec 80CCD(2)).
3. **Module 1.3 (Dual Regime Calculator):** Tax computation service (`TaxRegimeService`) computing Old Regime (with Chapter VI-A deductions) vs New Regime (Section 115BAC, without Chapter VI-A).
4. **Module 1.4 (Mandatory Legal Disclaimer Engine - FR16.4.1):** Enforces mandatory prominent warning banner across UI dashboards, PDF export footers/headers, and CSV export metadata.
5. **Module 1.5 (Backend API & Exporters):** API endpoint `GET /api/v1/tax/summary` and structured PDF/CSV export builders with legal disclaimers embedded.
6. **Module 1.6 (Frontend UI):** `TaxSummaryDashboard.tsx`, Old vs New Regime side-by-side comparison card, and FY selector dropdown (supporting FY 2021-22 to FY 2026-27).

---

## 2. Mandatory Non-Advisory & Legal Warning Disclaimer (FR16.4.1)

Per requirement **FR16.4.1**, every UI screen, exported PDF, exported CSV, and API payload generated by ArthSaarthi's tax module **MUST prominently display** the following explicit legal warning:

```text
+---------------------------------------------------------------------------------------------------+
|  ⚠️ IMPORTANT LEGAL NOTICE & TAX DISCLAIMER (FR16.4.1)                                             |
|                                                                                                   |
|  This Tax Readiness Summary and Tax Estimation tool is provided strictly for INFORMATIONAL,       |
|  EDUCATIONAL, AND TAX/INVESTMENT PLANNING PURPOSES ONLY.                                          |
|                                                                                                   |
|  1. The estimated tax calculations, exemptions, and regime comparisons shown DO NOT represent     |
|     actual final tax liabilities payable to the Income Tax Department.                            |
|  2. Tax laws, rules, deductions, and exemptions are subject to individual financial               |
|     circumstances, specific conditions, and statutory amendments.                                 |
|  3. Neither the application nor its developers/authors accept ANY RESPONSIBILITY OR LIABILITY     |
|     for any inaccuracies, calculation errors, tax penalties, interest, or financial losses.        |
|  4. For actual tax calculations, formal tax computation, and official Income Tax Return (ITR)     |
|     filing, users MUST consult a qualified Chartered Accountant (CA) or certified tax consultant.  |
+---------------------------------------------------------------------------------------------------+
```

### 2.1. Enforcement Locations
1. **UI Banners:** Rendered at the top of `TaxSummaryDashboard.tsx`, `IncomePage.tsx`, `DeductionsPage.tsx`, and `CapitalGainsPage.tsx` using a high-visibility alert container (`AlertAmber` / `BorderIndigo`).
2. **PDF Exports:** Printed at both the header and footer of generated Tax Summary PDF documents.
3. **CSV Exports:** Embedded in rows 1–4 of exported CSV files prior to financial data tables.
4. **API Responses:** Included as a top-level `disclaimer` field in `GET /api/v1/tax/summary` JSON response.

### 3.2. Year-over-Year Versioned Tax Rules Registry (`TaxRulesRegistry`)

```python
# backend/app/core/tax_rules_registry.py

MANDATORY_TAX_DISCLAIMER: str = (
    "This Tax Readiness Summary and Tax Estimation tool is provided strictly for "
    "informational, educational, and tax/investment planning purposes only. The "
    "estimated tax calculations shown do NOT represent actual final tax liabilities "
    "payable to the Income Tax Department. For actual tax calculations and filing ITR, "
    "users must consult a qualified Chartered Accountant (CA) or tax consultant."
)

class FinancialYearTaxRules(BaseModel):
    financial_year: str
    old_regime_standard_deduction: Decimal
    new_regime_standard_deduction: Decimal
    section_87a_old_limit: Decimal
    section_87a_new_limit: Decimal
    old_regime_slabs: List[Tuple[Decimal, Optional[Decimal], Decimal]]
    new_regime_slabs: List[Tuple[Decimal, Optional[Decimal], Decimal]]
    health_and_education_cess_rate: Decimal = Decimal("0.04")
    disclaimer: str = MANDATORY_TAX_DISCLAIMER
```

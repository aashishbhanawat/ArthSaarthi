# Release Scope & Requirements - v1.5.0 (Infrastructure, Data & Automation)

ArthSaarthi v1.5.0 focuses on **Infrastructure, Data & Automation**, introducing direct broker API integrations, an in-process background job scheduler, automated corporate action processing for bonds and equities, an edge-AI Market Research & Concall Intelligence feed, desktop auto-update notifications, and security hardening across server, desktop, and Android deployments.

---

## 1. Key Work Items & Features

### 1. Broker API Integration (Zerodha Kite & ICICI Breeze) (`NFR12`)
*   **Summary:** Connect Zerodha Kite and ICICI Breeze accounts directly from the Data Import page (`BrokerApiSyncCard.tsx`) to fetch live holdings and tradebooks without manual CSV exports.
*   **Security:** API secrets and access tokens are encrypted at rest in `broker_credentials` using AES-256-GCM (`KeyManager`), with strict PII-free debug logging (`#601`).

### 2. API Rate Limiting & Caching (`NFR13`)
*   **Summary:** Standardized rate-limit guards (`slowapi` / endpoint cooldowns) and multi-layer caching (Redis in server mode, DiskCache in desktop/Android modes) across market data, asset seeding, and news/concall endpoints.

### 3. In-Process Background Job Scheduler (`APScheduler`) (`FR17` / `NFR14`)
*   **Summary:** Integrated `AsyncIOScheduler` directly into FastAPI lifespan (`app/core/scheduler.py`) with `coalesce=True`, `max_instances=1`, and execution audit logging (`scheduled_job_logs`), plus an Admin Scheduler Dashboard (`SchedulerDashboard.tsx`).

### 4. Automated Bond & Stock Corporate Actions (`#562`, `#607`)
*   **Summary:**
    *   **Bond Engine:** Scheduled coupon payout cash credits and maturity redemptions with idempotency guards and user notification receipts (`corporate_action_events`).
    *   **Stock Engine:** Automated ingestion of stock dividends, splits, and bonus issues with interactive review/acknowledgement via `CorporateActionNotificationModal.tsx`.

### 5. Market Research & Concall Intelligence Feed (`FR8.2`, `FR8.2.1`, `FR8.2.2` / `#618`)
*   **Summary:**
    *   **Multi-Source Aggregation:** Aggregates NSE/BSE corporate filings, Trendlyne concall audio/transcripts, Yahoo Finance `.NS` RSS, and Google News broker research reports (`market_news_articles`).
    *   **Edge AI / Zero-LLM Concall Intelligence:** On-device CTranslate2 INT8 `faster-whisper` audio transcription with Indian financial phonetic calibration, official exchange PDF transcript auto-priority, and `yiyanghkust/finbert-tone` INT8 ONNX sentiment analysis.
    *   **Quantitative Analysis:** Prepared vs Q&A Tone Divergence Alerts, Loughran-McDonald Hedging & Uncertainty Index, 4-Aspect Financial Sentiment Scorecards (Demand, Margins, Guidance, CapEx), and Extractive Red Flags (`ConcallAnalysisModal.tsx`).
    *   **Model Management:** Admin UI (`AIModelManagementCard.tsx`) to download, verify, and manage local ONNX/Whisper models.

### 6. Desktop Update Notification (`FR-Desktop-2`)
*   **Summary:** Automatic GitHub Release version check on desktop startup with an interactive update banner guiding users to new releases.

### 7. Security Hardening (`#601`, `#602`, `#603`)
*   **Summary:**
    *   Removed raw PII payload debug dumps from `broker_api_parser.py` (`#601`).
    *   Added `ENVIRONMENT=production` execution guard to `backend/scripts/inspect_icici_raw.py` (`#602`).
    *   Enforced admin JWT authentication on `GET /api/v1/system/logs` and `POST /api/v1/system/snapshots/run-daily` in server/desktop modes while preserving Android WorkManager local access (`#603`).

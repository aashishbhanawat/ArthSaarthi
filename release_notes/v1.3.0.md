# ArthSaarthi v1.3.0 Release Notes

**Date:** August 13, 2026
**Version:** v1.3.0

## Highlights

ArthSaarthi v1.3.0 introduces major enhancements across **Security & Multi-Tenant Data Isolation, Financial Goal Analytics, Upstox V3 Market Data Provider, Grable & Lytton Risk Profiling, Android Background Portfolio Sync, and Application Performance**.

---

### 🚀 Key Features & Enhancements

- **Goal Required Monthly Contribution & Projections (FR13.3 & FR13.4):**
  - **SIP Contribution Engine:** Compounds linked assets to target date and calculates exact ordinary annuity required monthly SIP. Handles PV growth, 0% fallback, and target dates in the past.
  - **Growth Path Projections & XIRR:** Compiles dynamic XIRR across linked portfolios and standalone assets to plot target path vs projected growth trajectory. Generates real-time track status badges (`On Track` / `Off Track`).

- **Upstox V3 Provider Integration (#498):**
  - **Zero-Cost Market Data:** Integrated Upstox public V3 historical candles (`GET /v3/historical-candle/...`) and V2 market holidays API with 50 req/sec rate limiting.
  - **Asset Seeding & Cross-Verification:** Automatically downloads and caches `NSE.json.gz` from Upstox CDN to seed assets with ISIN $\leftrightarrow$ Symbol lookups.

- **Grable & Lytton 13-Question Risk Scale (#481):**
  - **Standardized Questionnaire:** Upgraded risk wizard to 13 questions with score calculation (up to 47 points) classifying users into Conservative, Moderate, Growth, and Aggressive risk profiles with target asset allocation breakdown.

- **Android Background Snapshot & Mobile Enablement (#492, #493, #494):**
  - **WorkManager Snapshot Sync:** Native Android `SnapshotWorker.kt` periodically updates daily portfolio snapshots in the background.
  - **Native Settings Toggle:** Profile page includes `AndroidSettingsCard` for toggling background sync.
  - **Pydantic V1 & SQLite Compatibility:** Fully stabilized Chaquopy Android runtime with custom bytes decoding and fallback ORM compatibility.

- **PPF & Fixed Income Security Enhancements:**
  - **Transaction Immutability:** System-generated PPF interest credit transactions are now immutable (edits/deletions blocked on API and UI).
  - **Multi-User Account Isolation:** Generates user-scoped PPF tickers (`PPF-{user_id_short}-{account_number}`) to prevent ticker collision across tenants.
  - **Updated Interest Rates:** Extended default PPF interest rates to 7.1% through Q3-2026 (September 30, 2026).

- **Performance & UX (Bolt & Palette):**
  - **Bulk Cache Invalidation:** Switched cache deletion to bulk operations (#420).
  - **Memoization:** Chart configurations, holdings calculations, group totals, and Watchlist tables memoized for smooth 60fps interaction.
  - **Accessibility:** Comprehensive ARIA labels across date inputs, close buttons, modal controls, and table action buttons.

---

### 🛡️ Security Fixes

- **Tax Report Endpoint Authorization (#423):** Enforced authentication and user-level data isolation on Capital Gains and Dividend report endpoints.
- **Goal Asset Linking Security (#434, #467):** Prevented IDOR vulnerability when linking portfolios or assets to goals.
- **Login Rate Limiting (#376):** Protected authentication endpoints against brute-force login attacks.

---

### 🐛 Bug Fixes & Stability

- **Transaction Response Validation (#510):** Added `FD_DEPOSIT` and `FD_MATURITY` to backend `TransactionType` schema, resolving FastAPI `ResponseValidationError`.
- **Sell Modal Tax Lot Scoping (#442, #443):** Scoped available tax lots in sell modal to active portfolio and adjusted lot quantities chronologically for stock splits and bonus issues.
- **Asset Seeding Heuristics (#438):** Prevented misclassifying stock names containing month-like substrings as `BOND`.
- **Backup Restoration Order (#441):** Ensured backup restores process buy transactions before sell transactions chronologically.

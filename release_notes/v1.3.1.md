# ArthSaarthi v1.3.1 Release Notes

**Date:** August 18, 2026  
**Version:** v1.3.1  

## Highlights

ArthSaarthi v1.3.1 is a critical patch release that resolves a database constraint conflict (`UniqueViolation` on `ix_assets_isin`) during Upstox metadata seeding when upgrading existing installations in Server (Docker / PostgreSQL) mode, and ensures session rollback safety across asset seeding and enrichment.

---

### 🐛 Bug Fixes & Stability

- **Upstox Metadata Unique ISIN Conflict Resolution:**
  - Added strict duplicate ISIN pre-verification in `process_upstox_metadata()` in `AssetSeeder`.
  - Skips updating an existing asset record with a new ISIN if that ISIN is already registered to another asset in the database, preventing PostgreSQL `psycopg2.errors.UniqueViolation` on `ix_assets_isin`.

- **SQLAlchemy Session PendingRollbackError Prevention:**
  - Added explicit `self.db.rollback()` in exception handlers for `process_upstox_metadata()` and `enrich_assets()`.
  - Ensures database exceptions during background asset seeding do not leave the session in a broken state, preventing backend container restart crash loops in Docker/PostgreSQL server deployments.
